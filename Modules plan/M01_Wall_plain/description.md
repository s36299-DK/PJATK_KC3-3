# M01 — Wall — Plain (facade panel)

**Dimensions:** 2.5 m (W) x 2.5 m (H) x 0.3 m (D)

## What the module is
Base wall panel of the modular kit. A flat stucco plane; the whole house facade is assembled by repeating this module horizontally and stacking it per floor (floor height 2.5 m).

## Materials
Stucco plaster, 4 color variants: cream, ochre, pink-terracotta, pale blue (variants = different materials on the same mesh).
