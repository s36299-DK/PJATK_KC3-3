# M03 — Wall — Window + Flower Box

**Dimensions:** 2.5 x 2.5 x 0.3 m, window 0.9 x 1.2 m, sill 1.1 m wide, box 0.9 x 0.3 x 0.25 m

## What the module is
Facade panel with window and a projecting stone sill carrying a terracotta flower box with a low-poly plant/flower cluster. The flower box is a signature element of the Italian facade — keep it.

## Materials
Stucco, stone sill, terracotta (box), wood/green (plants: simple low-poly leaf + flower spheres).
