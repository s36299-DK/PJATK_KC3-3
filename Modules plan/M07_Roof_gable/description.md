# M07 — Roof — Gable End Wall

**Dimensions:** base 2.5 m, gable height 1.25 m (pitch 30 deg), thickness 0.3 m

## What the module is
Triangular gable wall closing the end of the house. Stucco with a terracotta trim strip along both slope edges (where it meets the roof tiles).

## Materials
Stucco (triangle), terracotta (slope trim), stone optional (plinth variant).
